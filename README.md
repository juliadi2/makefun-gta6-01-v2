CAYO VERDE — an original open-world crime game in three.js. Explore a sun-soaked coastal city on foot and by car, steal cars, outrun the police across a 5-star wanted system, take on story missions for Mama Rosa, Vic Delgado and Sana, and build your fortune. Traffic, pedestrians, combat, a HUD with a live minimap, synthesized sound, and save/load — all in static files that run offline in desktop Chrome.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 and play with keyboard and mouse (WASD to move/drive, mouse to look, E to enter/exit cars, Shift to sprint, Space to jump/handbrake, click to shoot, Esc to pause).
